# Current Product Scope

Redwell Studio is currently focused ONLY on Collage.

## Active Feature

- Collage

## Temporarily Disabled Features

- Photo Editing
- Carousel

## Important Rule

Do not delete disabled Photo Editing or Carousel implementation.

They are intentionally preserved for possible future reactivation.

## Development Priority

Prioritize:

1. Collage functionality
2. Collage UX
3. Collage performance
4. Collage layouts/templates
5. Collage customization
6. Collage export
7. Stability and polish

Do not start implementing Photo Editing or Carousel unless explicitly requested.

## Safety Rule

Before modifying shared code, verify whether Collage depends on it.

## Product Philosophy

Prefer one polished core experience over multiple unfinished experiences.
